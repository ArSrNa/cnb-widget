# CNB 连接与认证意图

## 当前交付

- 首次打开进入首页，提供连接设置。用户不必配置 `CNB_TOKEN` 环境变量，可以直接填写个人访问令牌。
- 页面说明创建位置、所需只读权限、资源使用范围与组织角色限制。
- 认证优先级：应用会话或保存的 Token → `CNB_TOKEN` → cnb-cli 已有登录态。
- Token 先验证用户与组织读取能力，再保存；用量权限按组织检测，成员组织 403 显示无权限。
- 支持 macOS、Windows、Linux。主面板、悬浮球共享数据；灵动刘海仍仅在支持的 macOS 刘海屏显示。
- 默认使用系统凭据存储：macOS Keychain、Windows Credential Manager、Linux Secret Service。存储不可用时给出说明，用户可明确选择仅本次会话使用。
- 可更新或移除 Token；认证切换时清空旧数据并重新读取，避免跨账号混合。

## OAuth 后续意图

本次仅记录意图，不实现应用内 OAuth 按钮、设备授权、回调或刷新令牌流程。

后续接入 CNB OAuth Device Authorization Grant，用户在浏览器完成授权，应用管理授权等待、取消、过期、刷新和注销。申请范围覆盖用户身份、组织与仓库列表、组织资源用量、Issue 及评论读取。仍保留个人访问令牌方式和上述跨平台凭据存储。
