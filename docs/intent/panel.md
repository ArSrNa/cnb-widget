# 主面板意图（左右布局与组织二级导航）

> 2026-10-13 需求：主面板 UI 重构 —— 顶部横栏改为左右布局；一级导航（用量详情 / NPC 动态 / 设置）；用量详情下挂组织二级导航（含组织头像）；同步修复组件间距与内边距混乱问题。

## 1. 定位调整：从「纯设置中心」到「工作台」

- 前序定位（[display.md](./display.md) §5）：主面板只做设置与连接，不承载数据展示；
- 本次调整：主面板重新承载数据细看 —— 一级导航含「用量详情」「NPC 动态」「设置」三项；
- 与气泡面板的分工不变：
  - 气泡面板（悬浮球 / 刘海点击）= **瞥一眼**：轻量、不抢焦点、随用随收；
  - 主面板 = **坐下来看**：完整明细（逐组织用量、完整 issue 列表）+ 全部设置项。

## 2. 布局意图

- **左右两栏**：左侧功能导航栏 + 右侧内容区；
- **顶部不再有任何全局横栏** —— 原品牌行、组织 Tabs、设置入口按钮全部移除；品牌标识收进左侧栏顶部；
- **一级导航**（左侧栏）：用量详情 / NPC 动态 / 设置；
- **二级导航**：仅「用量详情」下挂 —— 逐个展示组织，点选切换右侧明细；
- **组织头像**：二级项优先展示真实组织 logo；获取不到时降级为首字母占位（方案与实测见 [../spec/panel-ui.md](../spec/panel-ui.md) §5）。

## 3. 观感要求（本次一并修复）

- 现状问题：组件之间与组件内部缺少 padding，内容挤在一起；根因是 `App.css` 样式层外的全局 `* { margin: 0; padding: 0 }` 覆盖了 Tailwind utility 和 shadcn 组件默认间距。
- 要求：**所有 UI 基于现成 shadcn/ui 组件重构**，包括主面板、刘海与悬浮球；使用 padding 保证组件内留白，用 gap 保证组件之间的间距。
- 不设禁止 padding 或禁止按尺寸调整组件布局的约束；内容区、卡片、列表和导航统一间距，适配 780×560 与最小 620×460 窗口；规范细则见 [../spec/panel-ui.md](../spec/panel-ui.md) §2。

## 4. 非目标（本次不做）

- 不新增数据源与维度（用量页仍按现有 mock / 后续 collector 数据渲染）；
- 不做主题切换（全应用固定暗色）；
- 不做侧栏图标折叠态（留作后续增强）。
