# 展示与交互意图

## 1. 有刘海屏幕

- **刘海胶囊（idle）**：刘海两侧各一枚小胶囊，视觉上与刘海融为一体；
  - 左侧：默认展示各组织 credit 汇总（环形进度或数字），指标可由用户更换（如 token 用量、构建次数）；
  - 右侧：NPC 工作状态圆点矩阵（黄=工作中 红=失败 蓝=待回复）。
- **hover 展开**：鼠标移入胶囊，展开为横条，逐组织列出 credit 用量；继续点击进入完整面板。
- **悬浮窗**：除刘海胶囊外，另提供一个可停靠的悬浮窗，用户可自定义展示内容（用量 / NPC 动态 / 二者组合）。

## 2. 无刘海屏幕（外接屏 / 老款 Mac）

- 仅悬浮窗形态：顶部居中小胶囊，与刘海胶囊视觉一致；
- hover 上后直接展开完整面板（无刘海则没有「贴 合」语义，hover 一步到位）；
- 面板内展示所有组织的用量汇总，**按组织切换**查看明细。

## 3. 面板内容（展开态）

- 组织分区：各组织 credit 用量进度条、本月消耗；
- 活跃 issue 列表：状态徽标 / 仓库 / 标题 / 最后动作时间，点击浏览器打开 issue；
- NPC 状态计数：工作中 / 待回复 / 失败。

## 4. 交互约束

- 非交互区域鼠标穿透，不遮挡下方应用点击；
- 事件提醒（NPC 完成 / 失败）以横幅弹出，6s 自动收回，全屏前台 App 时只收进胶囊不打横幅；
- 刘海几何探测依赖屏幕录制权限；无权限时全部降级为悬浮窗形态。
