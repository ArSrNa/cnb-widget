# 展示与交互意图

## 1. 灵动刘海（Notch）

- **可用性约束**：仅 MacBook 刘海屏（内建屏带物理刘海）可用；无刘海屏 / 外接屏下自动隐藏，主面板开关置灰；
- **刘海胶囊（idle）**：刘海两侧各一枚小胶囊，视觉上与刘海融为一体；
  - 左侧：默认展示各组织 credit 汇总（环形进度或数字），指标可由用户更换（如 token 用量、构建次数）；
  - 右侧：NPC 工作状态圆点矩阵（黄=工作中 红=失败 蓝=待回复）；
- **hover 展开**：鼠标移入胶囊，展开为横条，逐组织列出 credit 用量；继续点击进入详细面板。

## 2. 悬浮球（Float，2026-10-13 需求定形）

- **形态**：类似 360 加速球 —— **外圈进度环**，**内圈展示数字百分比**；
  - 进度环：当前口径下的用量百分比；口径 = 主面板配置的**单选组织 × 单选维度**（已确认，见 §5）；
  - 内圈数字：同口径百分比整数；
- **可拖动**：位置持久化（已实现），拖动与点击按位移阈值区分；
- **点击弹出气泡面板**（悬浮球旁弹出，不抢焦点）：展示更详细的信息：
  - 各组织的用量余额（各组织分块，按维度列出已用/剩余）；
  - issue NPC 对话情况（状态计数 + 活跃 issue 列表）；
- 展开面板形态见 [../spec/notch-ui.md](../spec/notch-ui.md) §3.2。

## 3. 详细面板内容（气泡，刘海/悬浮球共用）

- 组织分区：各组织 credit / 核时用量进度条、本月消耗、剩余额度；
- 活跃 issue 列表：状态徽标 / 仓库 / 标题 / 最后动作时间，点击浏览器打开 issue；
- NPC 状态计数：工作中 / 待回复 / 失败；
- 无权限的组织（charge 403）显示「无权限查看」，不阻塞其他组织。

## 4. 交互约束

- 非交互区域鼠标穿透，不遮挡下方应用点击；
- 事件提醒（NPC 完成 / 失败）以横幅弹出，6s 自动收回，全屏前台 App 时只收进胶囊不打横幅；
- 刘海几何探测依赖屏幕录制权限；无权限时全部降级为悬浮球形态。

## 5. 主面板对展示层的控制（2026-10-13 定稿）

- **显隐开关**：悬浮球、灵动刘海各自独立开关（已实现）；灵动刘海开关在无刘海屏时禁用并提示；
- **用量口径（已确认）**：**单选组织 × 单选维度** —— 悬浮球/刘海 idle 只显示该组织该维度的用量百分比，气泡面板内看全部组织明细；
  - 维度：credit、云原生开发核时、云原生构建核时（后续可扩展 GPU 核时、存储）；
  - 组织选项 = 组织白名单 ∩ owner 组织（成员组织 charge 403，见 [data.md](./data.md) §1）；
- **主面板定位**：工作台 —— 数据细看（用量详情 / NPC 动态）+ 设置与连接（显隐、口径、cnb-cli 安装/登录引导）；与气泡面板的分工及左右布局见 [panel.md](./panel.md)。
